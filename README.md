Automated Web Scraping & Data Extraction Pipeline

Project Overview

This project is a Python-based web scraping pipeline that extracts book information from Books to Scrape website.

Features

- Custom User-Agent headers
- Retry logic for failed requests
- Rate limiting to avoid excessive requests
- HTML parsing using BeautifulSoup
- Data cleaning using Pandas
- CSV data export
- Automatic summary report generation

Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas

Installation

Install the required dependencies:

pip install -r requirements.txt

Run the Project

python scraper.py

Output Files

- output.csv – Extracted book data
- summary_report.txt – Automatic scraping summary
